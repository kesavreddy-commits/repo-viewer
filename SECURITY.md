# Security

Please report security problems privately, not in a public issue:
[report a vulnerability](https://github.com/kesavreddy-commits/repoviewer/security/advisories/new)
(GitHub's private vulnerability reporting).

Say what you found, how to reproduce it, and which version (`claude plugin list` shows it). I'll
acknowledge the report, look into it, and publish a fix as a new release. Only the latest release is
supported.

What repoviewer can do on your machine is listed in the README's
[Privacy and safety](README.md#privacy-and-safety) section: it runs read-only `git` commands, writes
only a file you save in its editor, and sends nothing off your machine.
